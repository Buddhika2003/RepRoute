# RepRoute

**RepRoute** is an offline fitness tracking app built with React Native and Expo. It helps users record workouts, explore exercises, track progress, and manage training goals.

## Features

- **Home dashboard** — View weekly workout activity, total reps, streaks, and recent workout entries.
- **Workout log** — Record exercises with sets, reps, and weight.
- **Exercise library** — Search exercises and filter them by muscle group.
- **Progress tracking** — Review weekly workouts, completed sets, lifted volume, and activity.
- **Weekly volume comparison** — Compare training volume across four weeks.
- **Training goals** — Add and remove personal workout goals.
- **Profiles** — Create and switch between profiles on the same device.
- **Light and dark themes** — Change the app appearance from the Profile screen.
- **Local data storage** — Save app data on the device with AsyncStorage.
- **Offline support** — Core app features work without an internet connection.

## Built With

- React Native
- Expo
- Expo Router
- AsyncStorage
